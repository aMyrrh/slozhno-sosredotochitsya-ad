# Сложно сосредоточиться

Проектная работа курса «Фронтенд-разработка» (Яндекс Практикум): адаптивный лонгрид о том, почему трудно сконцентрироваться, в тёмной («Неон») и светлой («День») темах с автоматическим выбором темы по настройкам системы.

Репозиторий проекта: https://github.com/aMyrrh/slozhno-sosredotochitsya-ad

## Что сделано

- Семантическая разметка: шапка, секции со статьями-карточками, галерея, подвал; фавиконки и `meta color-scheme`.
- Mobile first: базовые стили для 375 px, медиазапросы от 768 px и от 1024 px, «резиновая» вёрстка на гридах.
- Шапка и подвал высотой в экран (`100vh`) с минимальной высотой из макета, декоративные уголки и точка «REC» на псевдоэлементах.
- Размер крупного заголовка через `clamp()`.
- Галерея на `grid-template-areas`, ленивая загрузка картинок (`loading="lazy"`).
- Темы на CSS-переменных: тёмная по умолчанию (`variables.css`), принудительное переключение классами `theme-dark` / `theme-light` и автоматическое через `prefers-color-scheme`.
- Состояния кнопок темы и ссылок: `:hover`, `:focus-visible`, активная кнопка.

## Структура

- `index.html` — страница
- `styles/variables.css` — переменные и их переопределение под экраны
- `styles/style.css` — основные стили и адаптив
- `styles/dark.css`, `styles/light.css` — переменные тем
- `styles/globals.css` — глобальные стили
- `fonts/` — шрифт IBM Plex Mono
- `scripts/script.js` — переключение темы

## Запуск

Откройте `index.html` в браузере.
